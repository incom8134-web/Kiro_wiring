Key design decisions:

1. **E-stop is a pure hard-wired self-holding loop:** mushroom NC → START (NO) ∥ K1 AUX (NO) → K1 coil. Works without software, drops out on a broken wire, no automatic restart.
2. **Jetson is upstream of K1** (COMPUTE_POWER) so it keeps running for logging and clean shutdown after an E-stop.
3. **No direct load on J12 GPIO.** NVIDIA carrier spec: J12 signals pass through TI TXB0108 translators, ±20 µA drive, pull-ups/pull-downs must be > 50 kΩ. Every GPIO uses a 74LVC1G17 buffer.
4. **Warning light fails to the warning state.** Light is ON whenever K1 is closed; it turns OFF only while the Jetson sends a ≥ 100 Hz pulse (charge-pump watchdog). Frozen, booting or crashed Jetson → light ON.
5. **REGULATED_12V is required** (LiFePO4 full charge 14.6 V > ST3215 limit 12.6 V).

## 7. GPIO assignment and configuration

Basis: NVIDIA Jetson Orin Nano Developer Kit Carrier Board Specification — J12 signals are 3.3 V; non-I²C pins go through TI TXB0108 translators with ±20 µA drive; external pull-ups/pull-downs must be > 50 kΩ.

| Signal | J12 pin | SoC name | Dir | Circuit | Safe default |
|---|---|---|---|---|---|
| BEACON_HOLDOFF_PULSE | 29 (proposed) | GPIO01 | out | R21 1 k → U60 74LVC1G17, R63 100 k pull-down | floating/low → no pulses → **light ON** |
| ESTOP_OK_N | 31 (proposed) | GPIO11 | in | U5 PC817 → R24 10 k pull-up → U21 buffer → R22 100 Ω | broken wire → HIGH → treated as E-stop |
| BEACON_STATE_N | 7 (proposed) | GPIO09 | in | U61 PC817 → R25 10 k → U22 buffer → R23 100 Ω | broken wire → HIGH → "light not on" → motion refused |
| LOGIC_3V3 | 1 | – | power | 3 buffers, < 1 mA total | – |
| JETSON_LOGIC_GND | 6 | – | GND | NT1 shows it is the same ground as the J16 return | – |

Rules
- **No hardware PWM on pin 29.** The pulse must stop when the software stops.
- First action at boot: pin 29 = output LOW. Wheel commands are refused until then.
- Shutdown / crash handler: zero velocity → torque off → leave pin 29 LOW (light on).
- Pinmux (Jetson-IO), state during boot and after GPIO cleanup for pins 29/31/7: measure on the bench before relying on them.
- Never connect a GPIO to 12 V, the battery, the lamp, a relay/contactor coil, a motor supply or a MOSFET gate.

## 9. Sequences

**Startup**
1. SW_MAIN on → Jetson boots (K1 open, no actuator power).
2. Software starts → pin 29 output LOW → wheel commands locked.
3. Release the mushroom if pressed → press START → K1 closes and self-holds.
4. Light comes on immediately → software sees ESTOP_OK_N LOW → starts the pulse → light off.
5. Servo torque on, motion allowed.

**Shutdown**
1. Stop motion, zero velocity, torque off → 2. press mushroom (K1 opens) → 3. shut down Jetson → 4. SW_MAIN off.

**Emergency stop**
1. Press mushroom → K1 opens at once → wheels, arms and light lose power; follower arm drops.
2. Jetson stays up, sees ESTOP_OK_N HIGH → commands zero, refuses motion, logs.
3. Clear the hazard → twist-release mushroom → press START deliberately → continue from startup step 4.

**Motion-warning light**

| Step | Action | Hardware |
|---|---|---|
| 1 | Non-zero wheel command received | – |
| 2 | MOTION_WARNING_REQUEST active = stop pulsing | C62 starts discharging |
| 3 | Light on; confirm BEACON_STATE_N LOW (timeout 0.5 s → refuse motion, log) | lit within ≈0.1–0.15 s (estimate) |
| 4 | Wait 0.5 s after confirmation | lit |
| 5 | Forward wheel command | lit |
| 6 | Stay lit while any command ≠ 0 | lit |
| 7 | After commands return to 0, stay lit 1.0 s | lit |
| 8 | Resume pulses → light off | – |

## 10. Warning-light wiring and control pseudocode

```text
Power:    12V_AFTER_CONTACTOR ─ F_BEACON 2A ─ BEACON_12V ─ J60.1 ─ beacon + … beacon − ─ J60.2 ─ Q1 D (IRLZ44N)
                                                                     Q1 S ─ POWER_GND
Gate:     BEACON_12V ─ R60 10k ─ BEACON_ENABLE ─ R61 100R ─ Q1 G ;  R62 100k + D63 15 V zener G-S
                                     └─ Q2 BSS138 drain ;  Q2 source ─ JETSON_LOGIC_GND
Watchdog: J12-29 ─ R21 1k ─ U60 74LVC1G17 ─ R64 220R ─ C61 1µF ─┬─ D60 BAT54 → GND
                                                               └─ D62 BAT54 ─ HOLDOFF_DC ─ Q2 G
                                                                   C62 1µF, R65 100k → GND (τ = 0.1 s)
Feedback: BEACON_12V ─ R66 4k7 ─ U61 LED ─ BEACON_OUT ;  U61 transistor → BEACON_STATE_N
```

Q1 rule: V_DS ≥ 30 V, I_D ≥ 3 × lamp current, R_DS(on) specified at V_GS = 10 V. IRLZ44N (55 V, 22 mΩ at 10 V, V_GS max ±16 V) is the generic choice; re-check once the lamp is measured.
Relay alternative not used: frequent switching, contact wear, and fail-to-warning is harder to achieve.

```python
# Wheel-command gate + warning light (pseudocode, 200 Hz loop)
STOPPED, ARMING, MOVING, STOPPING = range(4)
state = STOPPED; t = 0; t_conf = None; last_loop_ok = now(); holdoff_allowed = True

def boot():
    gpio_out(PIN29, LOW)               # first action; wheel commands refused before this
    start_heartbeat_thread()

def heartbeat_thread():                # separate thread, NOT hardware PWM
    while True:
        healthy = (now() - last_loop_ok) < 0.05 and holdoff_allowed
        gpio_write(PIN29, toggle() if healthy else LOW)   # >=100 Hz square wave = light off
        sleep(0.005)

def control_loop(cmd):                 # 200 Hz
    global state, t, t_conf, holdoff_allowed, last_loop_ok
    last_loop_ok = now()
    if gpio_read(PIN31_ESTOP_OK_N) == HIGH:          # E-stop or broken wire
        send_zero(); state = STOPPED; holdoff_allowed = True; log("ESTOP"); return
    moving_req = any(v != 0 for v in cmd)
    if state == STOPPED:
        send_zero()
        if moving_req: holdoff_allowed = False; t = now(); t_conf = None; state = ARMING
    elif state == ARMING:
        send_zero()
        if t_conf is None:                           # 1) wait for light confirmation
            if gpio_read(PIN7_BEACON_STATE_N) == LOW: t_conf = now()
            elif now() - t > 0.5:
                log("beacon not confirmed"); state = STOPPED; holdoff_allowed = True
        elif now() - t_conf >= 0.5: state = MOVING   # 2) 0.5 s after confirmation
    elif state == MOVING:
        if moving_req: send(cmd)
        else: send_zero(); t = now(); state = STOPPING
    elif state == STOPPING:
        send_zero()
        if moving_req: state = MOVING                # light never went off: no new wait
        elif now() - t >= 1.0: holdoff_allowed = True; state = STOPPED

def shutdown_or_crash():
    send_zero(); torque_off(); holdoff_allowed = False; gpio_write(PIN29, LOW)
```

The servo bus already reports speed (V1); it can serve as an extra ROBOT_MOVING confirmation. No encoder is added.

## 12. Bring-up checklist

1. ☐ All fuses removed. Check battery connector polarity with a meter.
2. ☐ Fit F_MAIN and F_CTRL only. Check star-point resistance.
3. ☐ E-stop loop test (no load fuses):
   - START → K1 pulls in and holds ☐ / mushroom → opens at once ☐ / releasing mushroom does not re-close ☐
   - Pull one loop wire → opens ☐ / remove F_CTRL → opens ☐ / TP74 = 0 V ☐
4. ☐ Fit F_JETSON → check TP72 → boot Jetson. **Measure J16 input current at 10–10.5 V.**
5. ☐ Connect buffer board → TP80 = 3.3 V; TP81 LOW with K1 closed, HIGH with K1 open.
6. ☐ Scope pins 29/31/7 during boot and after GPIO cleanup; record.
7. ☐ Measure beacon current at 12.0 V and 14.6 V; confirm F_BEACON 2 A and IRLZ44N are adequate.
8. ☐ Run the warning-light test (section 13).
9. ☐ Fit F_HUB → hub, LiDAR and three CH343 adapters enumerate.
10. ☐ Fit F_ARM_IN, F_LEADER, F_FOLLOWER → TP2/TP76/TP77 = 5 V → arm torque test.
11. ☐ Fit F_DRIVE → TP75 = 12 V no-load and loaded → wheel IDs 7–10 respond → slow drive test.
12. ☐ Repeat the E-stop test while driving; check the log.
