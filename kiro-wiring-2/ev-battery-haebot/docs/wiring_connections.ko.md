# 배선 연결표: HAEBOT EV 배터리 설계 (Rev B, 2026-11-26)

[English](wiring_connections.md) | [한국어](wiring_connections.ko.md)

[한국어 사진 배선 안내서](../exports/HAEBOT_EV_PHOTO_WIRING_GUIDE_KO.pdf)의 연결 ID는 영문 표와 같습니다.
이 표는 번역용 보충 자료이며 전기적 연결이나 정격을 변경하지 않습니다. KiCad 핀 이름은 기능 표기이며,
미확인 실제 부품 단자/Jetson 헤더 번호를 임의로 지정하지 않습니다. 전류·전선 선정 근거의 원문은
[영문 연결표](wiring_connections.md)와 [보호 계획](power_distribution_and_protection.md)에 있습니다.

## 전원 및 제어선

| ID | 출발 → 도착 | 전압 / 기능 | 확인 상태 |
|---|---|---|---|
| W01 | BT1 + → F1 → SW1 → U6 BAT+ → ESC+ → BATT_MON 분기 | 배터리 양극 전체 방전 경로 | 배터리 선택: VOLTON 12 V 45 Ah 리튬이온. 실제 전압 범위/BMS/커넥터 정격 미확인. F1 40 A 잠정 |
| W02 | BT1 - → 음극 스타 버스 | POWER_GND | 별도 귀환선 사용 |
| W03 | J2 충전 입력 → F2 → SW1 배터리 측 BATT_F | 배터리에 맞는 충전 경로 | 충전기/전압 미확인, F2 15 A 잠정 |
| W04 | BATT_MON → K1 주 접점 → U3 IN+ | MOTION_RAW | K1 정확한 모델/차단 정격 미확인 |
| W05 | U3 OUT+ → FB1 입력 스터드 | MOTION_12V, 정전압 12.0 V | U3 모델/최종 전류 정격 미정 |
| W06 | FB1 F11 → U30 VIN+ 나사 단자 | WHEEL_12V, 바퀴 분기, F11 15 A | 기존 V1 배치 기준 |
| W07 | FB1 F12 → U41 VIN+ 나사 단자 | ARM1_12V, 새 12 V 팔 1, F12 10 A 잠정 | 실제 서보/전류 확인 필요 |
| W08 | FB1 F13 → U42 VIN+ 나사 단자 | ARM2_12V, 새 12 V 팔 2, F13 10 A 잠정 | 실제 서보/전류 확인 필요 |
| W09 | U30/U41/U42 VIN-, U3 IN-/OUT- → 음극 스타 버스 | POWER_GND | 각 귀환선은 전원선과 같은 굵기의 별도 전선 |
| W10 | BATT_MON → F3 → U20 DC 잭 | JETSON_BATT, F3 5 A | DC 잭 5.5 x 2.5 mm, 중심 +. 비상정지 후 전원 유지 |
| W11 | BATT_MON → F4 → U4 IN+ | BUCK_IN, F4 10 A | EA75-5V 입력 |
| W12 | U4 OUT+ → FB2 입력 스터드 | RAIL_5V, 5.0-5.2 V | FB2는 5 V 전용 |
| W13 | FB2 F21 → 허브 1 DC 입력 | HUB1_5V, F21 3 A 잠정 | 허브 입력 전압/플러그 미확인 |
| W14 | FB2 F22 → 허브 2 DC 입력 | HUB2_5V, F22 3 A 잠정 | 허브 2 장착 여부/정격 미확인 |
| W15 | FB2 F23 → J5 AUX_5V → U6 소형 5V 핀 | 정전압 5 V, F23 2 A 잠정 | JST 하네스와 기타 보조 부하 정격 확인 필요 |
| W16 | BATT_MON → F5 → S1 래칭 NC → K1 코일 +, 코일 - → POWER_GND | 코일 전원 제어, F5 2 A 잠정 | 실제 코일 전류/전압/극성/연속 통전/서지 억제 및 S1 정격 확인 필요 |
| W17 | U30 포트 1 → M31 → M33, 포트 2 → M32 → M34 | 바퀴 서보 버스 | ID 7 → 9, ID 8 → 10의 체인 2개 |
| W18 | U41/U42 포트 1 → 각 로봇팔 서보 체인 | 새 12 V 팔 서보 버스 | 정확한 모델/배치/전류 확인 필요 |
| W19 | U6 G → 음극 스타 버스 | 모니터 회로용 POWER_GND | 대전류를 JST에 흘리지 않음 |

U4 컨버터 IN-와 OUT-도 각각 음극 스타 버스에 연결합니다. FB1/FB2에는 내부 음극 버스가 없습니다.
서보 어댑터의 전원은 DC+/DC- 나사 단자로 연결하고 배럴 잭을 사용하지 않습니다.

## I2C 및 USB

| ID | 연결 | 주의사항 |
|---|---|---|
| I-1 | U6 SDA → Jetson GPIO/I2C SDA | 실제 헤더 핀, 신호 전압/풀업 미확인 |
| I-2 | U6 SCL → Jetson GPIO/I2C SCL | 실제 헤더 핀, Linux 버스 및 드라이버 미확인 |
| U-1 | Jetson USB-A1/A2 → Gemini 335 / 손목 웹캠 | 허브 대신 Jetson에 직접 연결, USB 데이터 및 전원 |
| U-2 | Jetson USB-A3/A4 → 허브 1/2 업스트림 | USB 데이터, 허브 2는 미확인 |
| U-3 | 허브 1 DS1-DS3 → U30/U41/U42 USB-C | 통신/보드 로직용. 모터 전류 귀환 경로로 사용 금지 |
| U-4 | 허브 1 DS4 → RPLIDAR C1 어댑터 | USB 데이터 및 5 V 전원 |

J6는 기존 Jetson U20의 GPIO/I2C 헤더를 나타내는 기능 블록입니다. 새 장치를 추가하라는 뜻이 아닙니다.
U6의 기능 포트 BAT/LOAD/V5/GND는 실제 모듈의 BAT+/ESC+/5V/G 표기에 대응합니다. 사진 방향과 커넥터 삽입
방향을 실제 부품에서 확인하십시오. SDA/SCL은 USB나 DC 전원 잭에 연결하지 않습니다.

## NC 비상정지와 복구

**S1은 접촉기 주 전원 경로가 아니라 코일 공급에 직렬로 연결합니다.** 코일 공급은 K1 주 접점 앞의 BATT_MON에서
가져옵니다. S1이 해제되어 NC가 닫혀 있으면 코일에 전원이 공급됩니다. 누르면 NC가 열려 코일 공급이 끊기고
K1 주 접점이 열려 바퀴와 양쪽 팔 전원이 차단됩니다. 기계식 래치가 이 상태를 유지합니다.

**돌려 해제하면 모터 전원이 즉시 복구됩니다. 별도 START나 재시작 인터록은 없습니다.** Jetson·허브·Matek 회로
전원은 K1 앞에서 공급되므로 유지됩니다. 정지 중에도 K1의 배터리 측 대형 단자는 살아 있습니다. 팔의 유지 토크는
전원 차단 시 사라지므로 실제 시험에서는 팔을 지지하고 전원 복구 전 동작 명령을 해제하십시오.
