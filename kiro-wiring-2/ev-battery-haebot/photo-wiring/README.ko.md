## 보는 방법

1쪽의 빨간 선은 배터리/구동 양극, 주황색은 5 V 양극, 초록색은 접촉기 코일 제어입니다. 검정 **N**은 배터리
음극 스타 버스로 별도 귀환선을 연결하라는 뜻입니다. AC 중성선이 아니며 USB를 모터 전류 귀환선으로 사용하지
않습니다. 사진 속 위치만으로 극성을 정하지 말고 실제 부품의 + / - / NC 표기를 확인하십시오.

2쪽은 대형 주 전원 단자와 소형 코일 단자를 구분합니다. 비상정지 버튼을 누르면 NC 접점이 열려 **코일 공급이
끊기고** K1 주 접점이 열립니다. 버튼의 기계식 래치가 정지 상태를 유지합니다. 돌려 해제하면 모터 전원이 즉시
복구됩니다. 별도 START 버튼이나 재시작 인터록은 없습니다. Jetson·허브·Matek 회로 전원은 유지됩니다.

3쪽은 Matek BAT+/ESC+ 대전류 경로와 소형 5V/G/SDA/SCL 연결을 구분합니다. 서보 어댑터의 모터 전원은 초록색
DC+/DC- 나사 단자를 사용합니다. USB-C는 허브와 통신/보드 로직을 연결하고, 흰색 D/V/G 포트는 서보 버스입니다.

## 배터리 선택

사용자가 **VOLTON 12 V 45 Ah 리튬이온**을 선택하고 45 Ah 옵션을 확인했습니다. 제품 선정 정보는 이전의
배터리 미식별 상태를 대체하지만, 실제 팩의 직렬 셀 구성, 완전 충전/최저 전압, BMS 연속·순간 전류, 방전
케이블/커넥터 및 충전기는 여전히 확인이 필요합니다. Ah 용량으로 방전 전류 능력을 판단하지 마십시오.

- 사용자 선택 판매 페이지: https://www.coupang.com/vp/products/9101801616?vendorItemId=93727752087
- 제조사 45 Ah 제품: https://www.voltonbattery.com/12v/?idx=407

제품명만으로 3S라고 단정하거나 U3를 우회하지 않습니다. 사진 속 배럴 케이블이 로봇의 방전 출력이라고
가정하지 않습니다. 실제 팩의 충전/방전선, 극성과 허용 전류를 확인한 뒤 하네스를 만드십시오.

## 사진과 참고 그림 구분

| 그림 | 출처와 한계 |
|---|---|
| VOLTON 배터리 | 선택한 12 V 45 Ah 제품군의 제조사 사진. 실제 팩 라벨 확인 필요 |
| K1 접촉기 | 사용자 제공 실제 사진. 500A DC12V 표기만으로 연속/차단 정격이나 코일 극성이 확인되지 않음 |
| Matek | 제조사 사진. 사진의 예시 XT60 전선은 모듈에 포함되는 부품이 아님 |
| 서보 어댑터 | Waveshare Bus Servo Adapter (A) V1.1 제조사 사진. 실제 CH343 보드와 일치하는지 확인 필요 |
| Jetson | NVIDIA 하드웨어 배치 사진. 초록색 번호는 기능 설명 번호이며 GPIO 핀 번호가 아님 |
| EA75-5V | 기록된 컨버터 모델의 판매자 사진. 실제 단자 표기가 사진 방향보다 우선 |
| FB1 퓨즈 박스 | 기존 프로젝트의 3D 렌더링으로 외형 참고용. 사진 속 옛 퓨즈 값 대신 옆의 새 배선 표기를 따름 |
| 비상정지 버튼 | 필요한 래칭 NC 형식의 예시 그림. 특정 제품이 선정/구매된 것은 아님 |
| U3 | 모델 미선정 상태를 나타내는 점선 기능 블록 |

원본 이미지는 `assets/`에 보관하며 사진 자체를 수정하지 않고 문서의 표시 영역만 사용합니다.
세부 출처는 [이미지 출처 목록](assets/sources.json)과 [영문판 참고 링크](README.md)에 있습니다.

## 미확인 사항과 검토

K1 코일의 연속 통전·전류·전압·극성·서지 억제 방식, S1의 DC 유도성 부하 정격, 실제 Jetson I2C 헤더/풀업/IC/드라이버는
확인이 필요합니다. U6 소형 5V 핀은 F23/J5 정전압 5 V에만 연결하고 G는 POWER_GND에 연결합니다. 새 팔은 12 V이지만
서보 모델·전류·커넥터 정격은 미확인입니다. 실제 정격으로 보호 장치를 확정한 뒤 조립하십시오.

전원 차단 시 팔의 유지 토크가 사라집니다. 단일 접촉기의 주 접점이 용착되면 차단에 실패할 수 있으며 기능 안전은
검증되지 않았습니다. 실제 부하 연결 전 무전원 도통 시험과 지지된 상태의 동작 시험이 필요합니다.

한국어 3쪽 모두 PDF 렌더링으로 글자와 여백, 배선 표시를 확인했습니다. 영어 문장을 번역했으며 회로 연결이나 정격은
변경하지 않았습니다. 기존 KiCad 소스와 전기 회로 출력본도 변경하지 않았습니다.
